# نظام ستي ليدر صلاح الدين — دليل الرفع على GitHub و Railway

النظام موقع ويب يتكون من ثلاثة أجزاء:
- **الكود** على GitHub.
- **الخادم** وقاعدة بيانات PostgreSQL على Railway.
- **الرابط** أونلاين يعطيك إياه Railway.

لا توجد أي خدمة أخرى.

## محتويات المستودع

| الملف | وظيفته |
|---|---|
| `server.js` | الخادم: تسجيل الدخول، الصلاحيات، قاعدة البيانات، التحديث اللحظي |
| `public/index.html` | واجهة النظام كاملة |
| `package.json` | المكتبات المطلوبة وأمر التشغيل |
| `railway.json` | إعداد التشغيل على Railway |
| `.env.example` | المتغيرات المطلوبة (للمرجع فقط) |
| `.gitignore` | يمنع رفع الملفات غير الضرورية |

## الجزء الأول: رفع الكود على GitHub

### الطريقة أ: من المتصفح، بدون برامج
1. ادخل https://github.com وسجّل حساباً إذا لم يكن لديك.
2. اضغط **+** أعلى الصفحة ← **New repository**.
3. اكتب الاسم `baly-salahaddin-erp`، واختر **Private** حتى لا يراه أحد، ثم **Create repository**.
4. في صفحة المستودع اضغط **uploading an existing file**.
5. فك ضغط الملف `baly-erp.zip` على جهازك، وادخل إلى المجلد.
6. اسحب **كل ما بداخل المجلد** إلى الصفحة: `server.js` و`package.json` و`package-lock.json` و`railway.json` و`.gitignore` و`.env.example` و`README.md` ومجلد `public`.
   > ملفات `.gitignore` و`.env.example` قد تكون مخفية على جهازك. في ويندوز فعّل «إظهار العناصر المخفية». وجودها مفيد لكنه ليس ضرورياً للتشغيل.
7. اضغط **Commit changes**.

تأكد بعد الرفع أن الملف `public/index.html` يظهر داخل مجلد `public` في المستودع.

### الطريقة ب: من الطرفية (إذا كان Git مثبتاً)
```bash
cd baly-erp
git init
git add .
git commit -m "نظام ستي ليدر صلاح الدين"
git branch -M main
git remote add origin https://github.com/اسم-حسابك/baly-salahaddin-erp.git
git push -u origin main
```

## الجزء الثاني: التشغيل على Railway

### 1. إنشاء المشروع من GitHub
1. ادخل https://railway.com واضغط **Login**، ثم اختر **Login with GitHub**.
2. اضغط **New Project** ← **Deploy from GitHub repo**.
3. امنح Railway صلاحية الوصول للمستودع `baly-salahaddin-erp` واختره.
4. سيبدأ Railway أول تشغيل، وسيفشل لأن قاعدة البيانات غير موجودة بعد. هذا طبيعي.

### 2. إضافة قاعدة البيانات
1. داخل المشروع اضغط **Create** (أو **+ New**) ← **Database** ← **Add PostgreSQL**.
2. انتظر حتى تظهر خدمة **Postgres** بجانب خدمة الموقع.

### 3. إضافة المتغيرات
1. اضغط على **خدمة الموقع** (وليس Postgres) ← تبويب **Variables**.
2. اضغط **Raw Editor**، والصق السطور التالية بعد تعديل القيم:

```
DATABASE_URL=${{Postgres.DATABASE_URL}}
JWT_SECRET=اكتب_هنا_نصا_عشوائيا_طويلا_مثل_k8Hq2mZx9Lp4Vt7Rw3Ns6Yc1Bd5Fg0Ja
LEADER_EMAIL=بريدك@gmail.com
LEADER_PASSWORD=كلمة_مرور_قوية_لك
LEADER_NAME=اسمك
```

3. اضغط **Update Variables**. سيعيد Railway التشغيل تلقائياً.

| المتغير | معناه |
|---|---|
| `DATABASE_URL` | يربط الموقع بقاعدة Postgres. اكتبه **حرفياً** كما هو أعلاه |
| `JWT_SECRET` | مفتاح تشفير الجلسات. أي نص عشوائي من 32 حرفاً أو أكثر، ولا تشاركه مع أحد |
| `LEADER_EMAIL` / `LEADER_PASSWORD` | حساب دخول الستي ليدر، ويُنشأ تلقائياً عند التشغيل |
| `LEADER_NAME` | اسمك كما يظهر في النظام |

### 4. الحصول على الرابط
1. خدمة الموقع ← **Settings** ← **Networking** ← **Generate Domain**.
2. ستحصل على رابط مثل `https://baly-salahaddin-erp-production.up.railway.app`. هذا هو موقعك أونلاين.
3. لاسم أقصر: من نفس المكان اضغط على الرابط وعدّل الجزء الأول، أو اربط نطاقاً خاصاً بك من **Custom Domain**.

### 5. التأكد من العمل
- تبويب **Deployments** يجب أن يُظهر الحالة **Success**.
- في السجلات (**View logs**) ستظهر العبارتان «أُنشئ حساب الستي ليدر» و«النظام يعمل على المنفذ».
- افتح الرابط وسجّل الدخول ببريد وكلمة مرور الستي ليدر.

## أول استخدام
1. **الإعدادات ← تعديل الإعدادات**: راجع المبالغ والتارگت وشرائح العروض، ثم احفظ.
2. **الفريق ← + مدير مبيعات**: أضف المدراء.
3. بجانب كل مدير اضغط **إنشاء حساب دخول**، وأرسل له البريد وكلمة المرور التي تظهر لك.
4. أضف المروجين تحت كل مدير، وحدد المنطقة (سامراء أو تكريت).
5. **الميزانية والعروض ← تعديل الميزانية**: حدد ميزانية الشهر ووزّعها على الأسابيع.
6. ابدأ تسجيل الكباتن من صفحة **الكباتن**.

> للتجربة أولاً: **الإعدادات ← تحميل بيانات تجريبية**. تُحذف لاحقاً بزر واحد دون المساس ببياناتك.

## التحديثات لاحقاً
أي تعديل ترفعه على GitHub (على فرع `main`) ينشره Railway تلقائياً خلال دقيقة أو اثنتين. البيانات محفوظة في Postgres ولا تتأثر بالتحديث.

## كلمات المرور
- **الستي ليدر نسي كلمة مروره:** غيّر قيمة `LEADER_PASSWORD` في Railway ← Variables. يعيد الخادم التشغيل وتصبح الكلمة الجديدة فعّالة.
- **مدير المبيعات نسي كلمة مروره:** الستي ليدر يدخل **الفريق ← إدارة الحساب ← تعيين كلمة مرور جديدة**.
- **تغيير كلمة المرور:** كل مستخدم يستطيع تغييرها بنفسه من زر **كلمة المرور** أعلى الصفحة.
- **إيقاف وصول مدير مبيعات فوراً:** **الفريق ← إدارة الحساب ← سحب الصلاحية**.

## الصلاحيات (مفروضة في الخادم)
- **الستي ليدر:** كل الصفحات وكل التعديلات، والميزانية والعروض.
- **مدير المبيعات:**
  - اطلاع فقط على فريقه وتصدير قوائم فريقه.
  - لا يرى كباتن الفرق الأخرى ولا أرقامهم، ولا يرى الميزانية.
  - لوحة المتصدرين تظهر له الترتيب العام بالأرقام فقط.

## قواعد الحساب (قابلة للتعديل من الإعدادات)
- تسجيل فقط: 3,000 د.ع
- رحلة واحدة: 3,000 د.ع
- 3 رحلات: 6,000 د.ع للسيارة
- إذا تجاوزت نسبة السيارات التي حققت 3 رحلات 60% في أسبوع المروج، تُحسب كل سياراته ذلك الأسبوع بـ 15,000 د.ع.
- الأسبوع من السبت إلى الجمعة، والاستلام يوم الثلاثاء من الأسبوع التالي.
- العروض تُخصم من ميزانية الشهر وتُضاف لمستحقات المروج في أسبوعها.

## التكلفة
- Railway يعطي فترة تجريبية مجانية.
- بعدها خطة **Hobby** بنحو 5 دولارات شهرياً، تشمل تشغيل الموقع وقاعدة البيانات لهذا الحجم.
- **النسخ الاحتياطي:** من خدمة Postgres ← تبويب **Backups** يمكنك تفعيل نسخ احتياطية دورية.
